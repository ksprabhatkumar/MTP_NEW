CURRENT MODEL AND RECIPE
models/summer_dynamic.py preserves summer GIN aggregation multiplied by tanh
GIN attention, learned GIN self coefficients, GIN decoder, gated causal temporal
block, flattened node identity, mean pooling, LayerNorm and classifier.
The temporal source is a gated-convolution implementation, not selective-scan
Mamba. Do not change it silently while testing the graph.
Dynamic adjacency is computed from learned per-IMU causal descriptors using
the exact methodology's C/S/A equation, sender mask, diagonal removal and final
row normalization. Weighted summer GIN keeps its self contribution once. The
methodology's illustrative alternative message operator is not substituted.
Unavailable classifier outputs are masked; all-missing windows raise an explicit
unavailable/abstain error. Branch-scale balancing is a separately named ablation.

weight decay .0005, batch 64, OneCycle schedule once per epoch. User requested

used consistently for all controls rather than inventing a weaker baseline.
