## Proposed next method: utility-gated graph correction
Question: can a graph help selectively under stress while preserving a strong independently trained no-graph path?
1. Use each existing robust-no-graph checkpoint as the frozen shared backbone for ALL new arms in its fold/seed. Copy only shared encoder/temporal/head components deliberately; graph-specific prediction modules must be separately initialized with identical seeds across matched arms. Never mutate original checkpoints. This isolates incremental correction learning and avoids interpreting a disabled, jointly adapted graph as the no-graph baseline.
2. Keep receiver-blind donor prediction. Let h be frozen local features, c the learned residual and g in[0,1] a window-level gate. Compute p0=f(h), p1=f(h+c), and pg=f(h+g*c). Gate inputs are detached receiver features, prediction disagreement, available-sensor mask and donor quality/null summaries; no activity labels or true corruption indicator at inference. A zero gate exactly restores p0.
3. Train the correction with source ideal training recordings and the SAME frozen synthetic stress recipe as the matched pilot. Include class loss plus the existing reconstruction objective; retain a soft penalty relu(CE(p1,y)-CE(p0,y)) on clean samples to discourage harmful corrections. This is a training preference, not a guarantee of ideal performance preservation. Strong backbone may limit capacity; revise that only in a subsequent explicit experiment.
4. Train the gate in a separate phase after freezing the correction. Utility target on TRAIN examples is u=1 when stop_gradient[CE(p0,y)-CE(p1,y)] exceeds a fixed small margin (proposed0.02 nats), otherwise0. Fit BCE(g,u). This directly teaches the gate whether correction helps instead of equating synthetic corruption exposure with correction usefulness. Final interpolated prediction pg needs its own validation: a useful endpoint does not guarantee every intermediate gate improves classification. Utility labels are endogenous training targets, not observed physical placement labels.
5. No validation-self fitting of gates, thresholds, corruption or utility labels. All auxiliary learning uses the existing train indices, train-only normalization and ideal-based synthetic examples. Freeze exact loss weights, stage lengths, margin, gate inputs and checkpoint selection in a new specification BEFORE executing. Proposed0.02 margin and loss form above are design choices to finalize, not an authorized parameter search.
